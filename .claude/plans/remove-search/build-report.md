## What was implemented (per plan step)

- **Step 1 — paste flow creates a tracked draft application: done.**
  `backend/app/api/v1/apply.py`: added module-level `_upsert_draft_application()` (extracted from `/letter`, now called by both `/letter` and `/from-url`) and `_upsert_paste_job()`. Deviation from the plan's suggested PostgREST upsert: used select-then-insert with a conflict-retry instead of `upsert(on_conflict="url")`, because a PostgREST upsert would UPDATE the existing row's `id` to the new uuid, breaking application FKs (now RESTRICT). Both from-url branches (scraped and paste-text) create a `jobs` row (`source='paste'`, `description_snippet` capped at 500 chars, no raw job_text stored) plus a draft application, and `UrlLetterResponse` now returns `application_id` and `job_id`.
