📖 Developer Guide

Dutch job application automation — Opstap

Opstap helpt gebruikers een CV te uploaden of een profiel in te vullen, zoekt Nederlandse vacatureboards, en verstuurt AI-gegenereerde motivatiebrieven.

3Lokaal draaien

Web (Next.js)

cd web
npm install
npm run dev        # http://localhost:3000

cd backend
python -m venv venv

Maak backend/.env aan:

cd opstap

flutter run

8Supabase Edge Functions

Alle gedeployed op project rwwumtwelwncdqmvhdkt.

FunctieTriggerWat het doet
delete-accountWeb-app (invoke)Verwijdert auth-gebruiker + Storage-CV + cascade profiel/sollicitaties
warn-cv-expirypg_cron dagelijks 01:00 UTCE-mailt gebruikers wiens CV in ≤7 dagen verloopt
cleanup-expired-cvspg_cron dagelijks 02:30 UTCVerwijdert verlopen CV-bestanden uit Storage
purge-inactivepg_cron wekelijks zo 03:00 UTCRoept admin.deleteUser aan voor 90-dagen inactieve gebruikers

Secrets per functie instellen in Supabase-dashboard: alle functies vereisen SUPABASE_URL en SUPABASE_SERVICE_ROLE_KEY. warn-cv-expiry heeft ook SENDGRID_API_KEY + SENDGRID_FROM_EMAIL nodig.

9AVG / GDPR-compliance
RegelWaar afgedwongen
1. Expliciete toestemming vóór CV-uploadAVG-modal in onboarding-wizard + profielpagina — checkbox verplicht
2. Alleen EU-serversSupabase eu-central-1; Railway europe-west4; Claude verwerkt data alleen in transit
3. Alle data verwijderen op verzoekdelete-account Edge Function — cascade alles
4. CV-bewaartermijn (7/30/90 d) + waarschuwingRetentiekiezer bij upload; warn-cv-expiry edge fn; cleanup-expired-cvs
5. Geen AI-training / geen derdenAnthropic API-voorwaarden; brieftekst niet gelogd
6. 90-dagen inactiviteitspurgelast_active_at aangeraakt bij elke API-aanroep; purge-inactive edge fn
7. Elke geautomatiseerde beslissing zichtbaar + bewerkbaarBrief-preview — gebruiker kan aanpassen vóór versturen

11Nieuw scherm of endpoint toevoegen

Nieuw Flutter-scherm

  1. Maak lib/screens/<area>/<naam>_screen.dart aan als ConsumerWidget of ConsumerStatefulWidget
  2. Voeg een GoRoute toe in lib/core/router.dart
  3. Draai /dutch-copy-agent vóórdat het scherm als klaar wordt gemarkeerd
  4. Draai /avg-checker als het scherm gebruikersdata of CV-bestanden aanraakt

Nieuw backend-endpoint

  1. Voeg functie toe in het betreffende app/api/v1/*.py-router
  2. Voeg user_id: str = Depends(get_current_user_id) toe voor auth
  3. Draai /security-agent vóórdat je merget
  4. Draai /avg-checker als het endpoint persoonsgegevens verwerkt

Nieuwe Next.js-pagina (web)

  1. Maak web/src/app/<pad>/page.tsx aan
  2. Dashboard-pagina's erven auth via DashboardShell in dashboard/layout.tsx
  3. Publieke pagina's wikkelen in <PublicShell>
  4. Draai /dutch-copy voor review van Nederlandse teksten
