Code Changes

✅
Auth email confirmation flow
Built /auth/confirm (OTP verifier) and /register/bevestig (holding page). Without this, users who registered got a confirmation email but clicking it did nothing — they'd be stuck.
✅
Password reset flow
Built /forgot-password, /auth/reset callback, and /reset-password form. Enumeration-safe: always redirects to "sent" page regardless of whether the email exists.
✅
AVG consent modal before CV upload
Dutch law (AVG/GDPR) requires explicit informed consent before processing personal data. Modal shows purpose, retention period selector (7/30/90 days), and records avg_consent_given_at in the database.
✅
Writing style + send method in dashboard
Users can now choose Formeel / Informeel / Enthousiast for their motivation letter, and pick E-mail vs Webformulier. Gives the user control over how they come across to recruiters.
✅
Social login: Microsoft, Apple, Meta
Added OAuth buttons to login and register pages using supabase.auth.signInWithOAuth. Reduces friction — users don't need to remember a password if they have one of these accounts. ⚠️ Needs: OAuth credentials configured in Supabase dashboard before buttons go live
✅
Security fixes (HTML strip, email validation, suspension check)
Three issues flagged by the security agent: stored XSS via letter_nl (fixed with HTML strip validator), contact_email header injection (fixed with regex), and suspension check happening after an API call it should block (reordered).
✅
Migration 005: last_active_at + avg_consent_given_at
AVG Rule 6 requires auto-deletion after 90 days inactivity. last_active_at is now stamped on every profile update so the purge-inactive Edge Function can enforce this correctly.
✅
Legal pages: /voorwaarden, /misbruik, 404, error boundary
Dutch ToS and abuse reporting are legally required before going public. The error boundary prevents white-screen crashes from leaking to users.

Pending — Manual Steps Required

⚠️
Register opstap.nl domain
The domain is the linchpin: it unlocks email deliverability (sending from opstap.nl), Plausible analytics, and proper SEO. Register via SIDN-accredited registrar (e.g. TransIP, Versio).
Manual: go to transip.nl or versio.nl → search opstap.nl → register
⚠️
Activate SendGrid Sender Authentication for opstap.nl
Without domain authentication, emails arrive with "via sendgrid.net" in the from field — a spam signal. Requires adding SPF/DKIM DNS records after the domain is registered.
After domain: SendGrid → Settings → Sender Authentication → Authenticate Your Domain
⚠️
Activate Plausible analytics
Plausible is already wired in the code but needs a domain to track. Create account at plausible.io with opstap.nl after domain is registered.
After domain: plausible.io → Add Site → opstap.nl
⚠️
Configure OAuth providers in Supabase
Social login buttons are live in the UI but the providers (Microsoft Azure, Apple, Meta) need app credentials added in Supabase → Authentication → Providers before they actually work.
Microsoft: Azure Portal → App registrations. Meta: developers.facebook.com. Apple: needs Apple Developer ($99/yr).
