8AVG / GDPR-regels (ingebouwd in v1)
  1. Expliciete toestemmingspagina vóór elke CV-upload
  2. Alleen EU-servers — geen data verlaat de EU
  3. Gebruiker kan altijd alle gegevens verwijderen (Instellingen → Privacy)
  4. CV-bewaartermijn: door gebruiker instelbaar (7 / 30 / 90 dagen, standaard 30). Waarschuwingsmail 7 dagen voor verloop; automatisch verwijderd bij verloop tenzij verlengd.
  5. Geen CV-data gebruikt voor modeltraining of gedeeld met derden. Uitzondering: Claude API verwerkt CV voor extractie (aan gebruiker vermeld).
  6. Retentiebeleid: accountdata automatisch verwijderd na 90 dagen inactiviteit (met 30-dagen waarschuwing)
  7. Privacybeleid in de app (gewoon Nederlands, geen juridisch jargon)
  8. Elke geautomatiseerde beslissing (vacaturematch, brief) is zichtbaar en bewerkbaar
  9. Recht op gegevensexport — gebruiker kan alle data downloaden vanuit Instellingen
  10. Elke verstuurde sollicitatie wordt gelogd en is zichtbaar voor de gebruiker
