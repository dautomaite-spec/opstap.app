Auth flow

websupabase

  • Supabase SSR auth — cookies set server-side via @supabase/ssr
  • Login: /login → email/password or OAuth (Google, Outlook, Meta)
  • Register: /register → creates user + shows AVG consent before CV upload
  • Server actions in web/src/app/actions/auth.ts
  • Route protection: web/src/lib/supabase/server.ts createClient() in server components
  • Email redirect URL is derived dynamically from request.headers.get('host') — works on localhost, preview deploys, and production without hardcoding

Dashboard shell

web

  • web/src/app/dashboard/components/DashboardShell.tsx — client component, wraps all dashboard pages
  • Layout: h-screen overflow-hidden wrapper + collapsible sidebar + overflow-auto main
  • Sidebar collapses to 64px icon-only mode; expanded width 240px
  • Organic wave SVG on sidebar right edge; decorative circles in SVG background
Gotcha: overflow: hidden on position: sticky elements breaks sticky behaviour. Keep overflow on the inner wrapper div, not the <aside>.

Public pages

web

  • PublicShell.tsx — server component, handles auth state for nav CTA
  • Layout: h-screen overflow-hidden + overflow-auto on <main> — sidebar always visible
  • Fixed decorative blobs (position: fixed, z-index: 0) in PublicShell — stay in place while content scrolls
  • Mobile: top bar fixed + hamburger → PublicMobileMenu.tsx drawer
  • Pages: /, /login, /register, /faq, /contact, /over-ons, /privacy, /blog
  • Over-ons: AVG/legal copy moved to a small collapsed "Juridisch" footer section — not prominent, meets disclosure requirements

Design system

web

  • Tailwind v4 — config in web/src/app/globals.css
  • CSS variables: --color-indigo-primary, --color-lavender-bg, --color-lavender-card, --color-text-primary, --color-text-muted, --color-white
  • Dark mode supported via .dark class on <html>
  • Organic blob shapes: CSS border-radius morphing e.g. 62% 38% 46% 54% / 58% 44% 56% 42%
  • Sidebar wave: 40px wide SVG overlay at right: 0 painting --color-lavender-bg in a wave path

Backend API

backend

  • Python FastAPI at https://opstapapp-production.up.railway.app
  • API client: web/src/lib/api.ts
  • Admin routes protected by x-admin-key header (set in Railway env: ADMIN_API_KEY)
  • Proxy: web/src/app/proxy.ts — replaced deprecated middleware.ts

AVG / GDPR

supabasebackend

  • Explicit consent gate before any CV upload
  • EU servers only — Supabase EU West, Railway EU
  • CV retention: user-defined 7 / 30 / 90 days (default 30). Auto-deleted on expiry
  • 7-day warning email before auto-delete (Supabase Edge Function + cron)
  • Account delete: wipes all data including CV and application history
  • No data used for AI training, no sharing with third parties

Contact form

web

  • Route: /contact — server component + ContactForm.tsx client component
  • Type dropdown: Gebruiker / Bedrijf; conditional subject list per type
  • Captcha: Cloudflare Turnstile (@marsidev/react-turnstile) — GDPR-friendly, free up to 1M/month
  • Honeypot: hidden name="website" input to catch bots
  • Server action: web/src/app/contact/actions.ts — validates, verifies captcha, sends via SendGrid
  • Sends to info@opstapapp.nl from noreply@opstapapp.nl
  • Env vars needed: TURNSTILE_SECRET_KEY, SENDGRID_API_KEY (set on Vercel)

Sidebar design

web

  • Organic right edge: 40px SVG overlay at right: 0 with preserveAspectRatio="none" — adapts to any viewport height
  • Decorative circles: SVG in sidebar background, zIndex: 0, low opacity (3–6%)
  • Background colour on inner <div> (not <aside>) to keep sticky/fixed behaviour intact
  • Fixed via h-screen layout on the shell wrapper — scroll overflow on <main> only

Privacy page

web

  • Route: /privacy — static server component, no client JS needed
  • Full AVG-compliant Dutch privacy policy — plain language, no legalese
  • Covers: data collected, purpose, retention periods, user rights (inzage, correctie, verwijdering, overdraagbaarheid), contactgegevens DPO
  • Linked from footer on all public pages and from the over-ons "Juridisch" section

Analytics (Plausible)

web

  • Cookieless, AVG-safe — no consent banner required
  • Script domain driven by NEXT_PUBLIC_PLAUSIBLE_DOMAIN env var — was previously hardcoded to opstapapp.nl
  • Set in Vercel env vars; falls back gracefully if not set (script not injected)
  • Plausible account still pending activation on live domain
